# DPW Modul 3 — Starter Artefak

Broker utama: Apache Kafka, single broker KRaft, dijalankan melalui Docker Compose.

## Quick Start
1. `pip install -r requirements.txt`
2. `docker compose up -d`
3. Buat topic `dpw3-events` dengan 3 partitions sesuai instruksi Bagian 3.
4. Ikuti Bagian 3 secara berurutan.

## Aturan
Jangan mengubah source code atau docker-compose.yml kecuali instruksi modul secara eksplisit memintanya.
